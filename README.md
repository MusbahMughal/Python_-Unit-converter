# GIAIC-QUATER_3 Project: Interactive Unit Converter

This repository contains a user-friendly web application built with Streamlit for the GIAIC (likely a specific program or course) Quarter 3 project. This application provides a simple and intuitive interface to instantly convert between various units of **length**, **weight**, and **time**.

## Key Features:

* **Real-time Conversion:** Get instant results as you input values.
* **Categorized Conversions:** Easily select the type of unit conversion you need (Length, Weight, Time).
* **Clear and Simple Interface:** Designed for ease of use, even for those unfamiliar with unit conversions.
* **Supports Common Units:**
    * **Length:** Miles ↔ Kilometers
    * **Weight:** Kilograms ↔ Pounds
    * **Time:** Seconds ↔ Minutes, Minutes ↔ Seconds, Minutes ↔ Hours, Hours ↔ Minutes, Hours ↔ Days, Days ↔ Hours

## How to Run:

1.  **Ensure Streamlit is installed:** If you haven't already, install Streamlit using pip:
    ```bash
    pip install streamlit
    ```
2.  **Navigate to the project directory:** Open your terminal or command prompt and go to the folder where you have saved the `converter_app.py` file (likely within this repository).
    ```bash
    cd GIAIC-QUATER_3-PROJECT/unit converter  # Adjust path if necessary
    ```
3.  **Run the Streamlit app:** Execute the following command:
    ```bash
    streamlit run converter_app.py
    ```

This will automatically open the unit converter application in your web browser.

## Usage:

1.  **Choose a category:** Select "Length", "Weight", or "Time" from the dropdown menu.
2.  **Select the conversion type:** A second dropdown will appear with the available conversions for your chosen category.
3.  **Enter the value:** Type the number you want to convert into the input field.
4.  **Click "Convert":** The converted result will be displayed below the button.

## Project Context:

This project was developed as part of the GIAIC Quarter 3 curriculum, demonstrating practical application of Python and the Streamlit library for creating interactive web applications.
